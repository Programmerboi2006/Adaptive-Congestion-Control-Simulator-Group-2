# Suggested Four-Member Contribution Division

**Member 1 — Simulation algorithms**
- Tahoe, Reno, AIMD controller classes.
- Congestion-control formulas.
- Algorithm-focused tests.

**Member 2 — Simulation and metrics**
- Round-based event model.
- Reproducibility and scenarios.
- Throughput, loss, cwnd, congestion-event and recovery calculations.

**Member 3 — Streamlit interface and visualization**
- Dashboard, workspace, comparison, scenario and analysis pages.
- Plotly charts and tables.
- UI validation messages.

**Member 4 — Testing, exports and documentation**
- pytest validation.
- CSV/JSON export.
- README, architecture, protocol explanation, presentation and viva preparation.

Everyone should understand the three algorithms, cwnd/ssthresh, RTT, packet loss, the simulation assumptions, and the limitations.
